## 5. 架构设计模式

### MVVM 架构
```
View (UI)  ←→  ViewModel (逻辑)  ←→  Model (数据)
```

### 设计原则应用
- **S**: 各模块职责单一（Router只管路由，Provider只管网络）
- **O**: 开放封闭，拦截器可扩展但不可修改核心逻辑
- **L**: 替换成本低，BaseProvider可被继承扩展
- **I**: 接口专一，每个拦截器只做一件事
- **D**: 依赖抽象，ViewModel依赖Model接口而非实现

### 关键设计
1. **路由拦截**: `pushWithLogin()` 实现登录保护
2. **环境切换**: `EnvironmentManager` 支持多环境配置
3. **拦截器链**: 请求/响应拦截器责任链模式
4. **泛型封装**: `get<T>()` / `post<T>()` 类型安全请求
