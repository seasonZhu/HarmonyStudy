## 一、概述

动画是提升用户体验的重要手段，合理的动画效果可以让界面更加流畅、自然，增加用户的操作反馈感。本文档介绍 ArkUI 中的动画实现方案。

### 1.1 动画类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 属性动画 | 改变组件属性值 | 透明度、缩放、位移、旋转等 |
| 过渡动画 | 组件出现/消失时的效果 | 页面转场、列表项增删 |
| 骨架屏动画 | 占位内容的闪烁效果 | 加载状态展示 |
| 组合动画 | 多个动画组合 | 复杂交互效果 |

### 1.2 动画性能原则

1. **尽量使用 GPU 加速属性**：transform、opacity 等
2. **避免在动画中创建新对象**
3. **控制动画时长**：一般 200-500ms 为宜
4. **使用合适的缓动曲线**

## 二、属性动画

### 2.1 animateToImmediately 使用

```typescript
// 基本语法
animateToImmediately({
  duration: 300,      // 动画时长（毫秒）
  curve: Curves.EaseOut, // 缓动曲线
  delay: 0,           // 延迟时间
  iterations: 1,      // 迭代次数
  playMode: PlayMode.Normal // 播放模式
}, () => {
  // 动画结束时的属性值
  this.opacityValue = 1
})
```

### 2.2 常用动画属性

| 属性 | 类型 | 性能 |
|------|------|------|
| opacity | number | 优 |
| scale | ScaleOptions | 优 |
| translate | TranslateOptions | 优 |
| rotate | RotateOptions | 优 |
| width/height | number | 差 |
| backgroundColor | Color | 中 |

### 2.3 缓动曲线

```typescript
// 内置曲线
Curves.linear          // 线性
Curves.ease           // 缓入缓出
Curves.easeOut        // 快入慢出
Curves.easeIn         // 慢入快出
Curves.easeOutCubic   // 默认曲线
Curves.easeInOut      // 慢入慢出

// 弹簧效果
Curves.responsiveSpring // 响应式弹簧
Curves.spring          // 普通弹簧

// 自定义曲线
Curves.cubicBezier(0.25, 0.1, 0.25, 1.0)
```

## 三、动画工具类封装

### 3.1 动画工具类设计

```typescript
export class AnimationUtils {
  // 淡入淡出
  static fadeIn(target: AnimatableProperty<number>, duration: number): void
  static fadeOut(target: AnimatableProperty<number>, duration: number): void

  // 缩放
  static scaleIn(target: AnimatableProperty<number>, duration: number): void
  static scaleOut(target: AnimatableProperty<number>, duration: number): void

  // 滑动
  static slideInFromLeft(target: AnimatableProperty<number>, duration: number): void
  static slideInFromBottom(target: AnimatableProperty<number>, duration: number): void

  // 旋转
  static rotateIn(target: AnimatableProperty<number>, duration: number): void

  // 组合
  static bounce(target: AnimatableProperty<number>, scaleProperty: AnimatableProperty<number>): void
}
```

### 3.2 使用示例

```typescript
// 淡入动画
AnimationUtils.fadeIn(this.opacityValue, 300)

// 缩放动画
AnimationUtils.scaleIn(this.scaleValue, 300)

// 组合动画
AnimationUtils.playTogether(
  () => AnimationUtils.fadeIn(this.opacityValue, 300),
  () => AnimationUtils.scaleIn(this.scaleValue, 300)
)
```

## 四、过渡动画

### 4.1 组件过渡效果

```typescript
// 添加过渡效果
Column()
  .transition(
    TransitionEffect.OPACITY
      .animation({ duration: 300, curve: Curves.EaseOut })
  )
```

### 4.2 非对称过渡

```typescript
TransitionEffect.asymmetric(
  TransitionEffect.translate({ x: 300, y: 0 })
    .animation({ duration: 300, curve: Curves.EaseOut }),  // 入场
  TransitionEffect.translate({ x: -300, y: 0 })
    .animation({ duration: 200, curve: Curves.EaseIn })   // 退场
)
```

### 4.3 常用过渡效果

| 效果 | 说明 |
|------|------|
| TransitionEffect.OPACITY | 透明度过渡 |
| TransitionEffect.translate | 位移过渡 |
| TransitionEffect.scale | 缩放过渡 |
| TransitionEffect.rotate | 旋转过渡 |
| TransitionEffect.asymmetric | 非对称过渡 |

## 五、骨架屏动画

### 5.1 骨架屏原理

骨架屏动画通过改变占位元素的透明度来模拟加载效果：

```typescript
// 创建闪烁动画
animateToImmediately({
  duration: 1500,
  curve: Curves.Linear,
  iterations: -1,  // 无限循环
  playMode: PlayMode.Alternate  // 来回播放
}, () => {
  this.shimmerOpacity = 0.3
})
```

### 5.2 骨架屏组件

```typescript
@Component
struct ShimmerPlaceholder {
  @Link shimmerOpacity: number

  build() {
    Column() {
      Row() {
        // 头像占位
        Column()
          .width(60)
          .height(60)
          .backgroundColor('#E0E0E0')
          .borderRadius(8)
          .opacity(this.shimmerOpacity)

        // 文字占位
        Column({ space: 8 }) {
          Rectangle()
            .width('80%')
            .height(16)
            .backgroundColor('#E0E0E0')
            .borderRadius(4)
            .opacity(this.shimmerOpacity)

          Rectangle()
            .width('60%')
            .height(12)
            .backgroundColor('#E0E0E0')
            .borderRadius(4)
            .opacity(this.shimmerOpacity)
        }
      }
    }
  }
}
```

```typescript
ListItem()
  .transition(
    TransitionEffect.OPACITY
      .animation({ duration: 300 })
      .combine(TransitionEffect.translate({ y: -50 }))
  )
```

### 6.2 LazyForEach 动画支持

```typescript
LazyForEach(
  (data: Article[]) => data,
  (article: Article) => article.id,
  (article: Article, index: number) => {
    ListItem()
      .transition(
        TransitionEffect.scale({ scaleX: 0.9, scaleY: 0.9 })
          .animation({ duration: 200, delay: index * 50 })
      )
      .opacity(article.isNew ? 0 : 1)
  }
)
```

## 七、首页转场动画

### 7.1 点击文章缩放效果

```typescript
@State selectedArticle: Article | null = null
@State scaleValue: number = 1

// 文章点击
ArticleCell()
  .onClick(() => {
    // 缩放动画
    animateToImmediately({
      duration: 200,
      curve: Curves.easeOut

      this.scaleValue = 0.95

    setTimeout(() => {
      // 跳转到详情页

```

## 八、性能优化

### 8.1 GPU 加速属性

优先使用以下属性（GPU 加速）：
- opacity
- transform (translate, scale, rotate)
- clip

避免频繁改变以下属性：
- width, height
- padding, margin
- backgroundColor

### 8.2 动画优化建议

```typescript
// 建议：使用 transform
Column()
  .translate({ x: this.offsetX })  // GPU 加速

// 避免：直接改变位置
Column()
  .position({ x: this.offsetX, y: this.offsetY })  // 触发重排
```

### 8.3 动画防抖

```typescript
// 防止动画抖动
if (Math.abs(newValue - oldValue) < 1) {
  return
}
```

## 九、实践总结

### 9.1 常用动画场景

| 场景 | 推荐动画 |
|------|----------|
| 页面加载 | 骨架屏 + 淡入 |
| 列表下拉 | 弹性回弹效果 |
| 列表项点击 | 轻微缩放反馈 |
| 收藏成功 | 弹跳 + 图标变化 |
| 删除确认 | 滑动删除 |
| 页面转场 | 共享元素过渡 |

### 9.2 动画时间参考

| 动画类型 | 推荐时长 |
|----------|----------|
| 微交互 | 100-200ms |
| 标准动画 | 200-400ms |
| 复杂动画 | 400-600ms |
| 页面转场 | 300-500ms |

### 9.3 动画曲线选择

| 效果 | 推荐曲线 |
|------|----------|
| 自然流畅 | Curves.easeOut |
| 快速响应 | Curves.easeOutCubic |
| 弹性效果 | Curves.responsiveSpring |
| 线性运动 | Curves.linear |
