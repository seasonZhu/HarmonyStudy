## 一、概述

手势交互是移动应用的重要组成部分，良好的手势处理可以提升用户体验。本文介绍 ArkUI 中的手势处理方案。

### 1.1 支持的手势类型

| 手势类型 | 说明 | 常用场景 |
|----------|------|----------|
| TapGesture | 点击 | 按钮点击、选择 |
| LongPressGesture | 长按 | 上下文菜单 |
| PanGesture | 滑动 | 拖拽、滑动删除 |
| PinchGesture | 捏合 | 缩放 |
| RotationGesture | 旋转 | 图片旋转 |
| SwipeGesture | 快速滑动 | 切换页面 |

### 1.2 手势优先级

- **手势组 (GestureGroup)**：用于组合多个手势
- **互斥模式 (Exclusive)**：同时只能识别一个手势
- **并行模式 (Parallel)**：可以同时识别多个手势

## 三、手势处理器封装

### 3.1 滑动删除

```typescript
createSwipeToDelete(onDelete: () => void, threshold: number = 100) {
  return new GestureGroup(GestureMode.Exclusive,
    PanGesture()
      .onActionUpdate((event: GestureEvent) => {
        // 限制只能向左滑
        if (event.globalX < startX) {
          offsetX = event.globalX - startX
        }
      })
      .onActionEnd((event: GestureEvent) => {
        if (Math.abs(offsetX) > threshold) {
          onDelete()
        }
      })
  )
}
```

### 3.2 长按菜单

```typescript
createLongPressMenu(menuItems: MenuItem[]) {
```

### 3.3 拖拽排序

```typescript
createDragSort(
  dataSource: any[],
  onReorder: (from: number, to: number) => void
) {
  return new GestureGroup(GestureMode.Exclusive,
    PanGesture()
      .onActionStart((event: GestureEvent) => {
        dragIndex = calculateIndex(event.globalY)
      })
      .onActionUpdate((event: GestureEvent) => {
        targetIndex = calculateIndex(event.globalY)
        // 更新 UI 显示拖拽位置
      })
      .onActionEnd(() => {
        if (dragIndex !== targetIndex) {
          onReorder(dragIndex, targetIndex)
        }
      })
  )
}
```

## 四、收藏页面滑动删除实现

### 4.1 组件结构

```typescript
@Entry
@Component
struct MyCollect {
  @State collections: Article[] = []

  build() {
    List() {
      ForEach(this.collections, (article: Article, index: number) => {
        ListItem() {
          SwipeableItem({
            article: article,
            onDelete: () => this.deleteCollection(index)
          })
        }
      })
    }
  }
}
```

### 4.2 可滑动项组件

```typescript
@Component
struct SwipeableItem {
  @ObjectLink article: Article
  @State offsetX: number = 0
  private DELETE_THRESHOLD = -80

  build() {
    Stack() {
      // 背景层（删除按钮）
      Row() {
        Text('删除')
          .fontColor('#FFFFFF')
          .width(80)
          .height('100%')
          .backgroundColor('#FF4444')
          .textAlign(TextAlign.Center)
      }
      .align(Alignment.End)

      // 前景层（内容）
      Row() {
        ArticleCell({ article: this.article })
      }
      .width('100%')
      .translate({ x: this.offsetX })
      .gesture(
        PanGesture()
          .onActionUpdate((event) => {
            // 限制滑动范围
            if (event.globalX < this.DELETE_THRESHOLD) {
              this.offsetX = this.DELETE_THRESHOLD
            } else if (event.globalX > 0) {
              this.offsetX = 0
            } else {
              this.offsetX = event.globalX - 50
            }
          })
          .onActionEnd(() => {
            if (this.offsetX < this.DELETE_THRESHOLD) {
              // 触发删除
              animateToImmediately({
                duration: 200
              }, () => {
                this.offsetX = -300  // 完全滑出
              })
              // 延迟执行删除（等待动画）
              setTimeout(() => {
                this.onDelete()
              }, 200)
            } else {
              // 重置
              animateToImmediately({
                duration: 200
              }, () => {
                this.offsetX = 0
              })
            }
          })
      )
    }
    .height(80)
    .width('100%')
  }
}
```

### 4.3 删除逻辑

```typescript
async deleteCollection(index: number): Promise<void> {
  const article = this.collections[index]

  // 先从本地移除
  await ArticleRepository.getInstance().uncollectArticle(article.id)

  // 从列表移除
  animateToImmediately({
    duration: 200
  }, () => {
    this.collections.splice(index, 1)
  })

  // 显示提示
  ToastUtil.show('已取消收藏')
}
```

## 五、双向滑动刷新

### 5.1 下拉刷新

```typescript
@State refreshOffset: number = 0
@State isRefreshing: boolean = false

List()
  .onScrollFrame((offset: number, state: ScrollState) => {
    if (offset < 0 && !this.isRefreshing) {
      // 下拉
      this.refreshOffset = Math.abs(offset)
    }
  })
  .gesture(
    PanGesture()
      .onActionEnd(() => {
        if (this.refreshOffset > 80 && !this.isRefreshing) {
          this.isRefreshing = true
          // 触发刷新
          this.refresh()
        }
      })
  )
```

## 七、性能优化

### 7.1 避免频繁状态更新

```typescript
// 避免：在滑动中更新状态
.onActionUpdate((event) => {
  this.offsetX = event.globalX  // 可能导致卡顿
})

// 推荐：限制更新频率
.onActionUpdate((event) => {
  if (Math.abs(event.globalX - lastX) > 2) {
    this.offsetX = event.globalX
    lastX = event.globalX
  }
})
```

### 7.2 使用 transform

```typescript
// 推荐：使用 transform
Row()
  .translate({ x: this.offsetX })

// 避免：使用 position
Row()
  .position({ x: this.offsetX })
```


## 八、实践总结

### 8.1 常用手势场景

| 场景 | 手势类型 | 实现要点 |
|------|----------|----------|
| 点击按钮 | TapGesture | count 属性 |
| 滑动删除 | PanGesture | 方向限制、阈值判断 |
| 长按菜单 | LongPressGesture | 触发时机 |
| 拖拽排序 | PanGesture | 位置计算 |
| 双击缩放 | TapGesture | count=2 |
| 页面切换 | SwipeGesture | 方向判断 |
| 图片缩放 | PinchGesture | scale 值 |
| 图片旋转 | RotationGesture | angle 值 |

### 8.2 手势设计原则

1. **符合用户预期**：手势动作应与操作结果有逻辑关联
2. **提供操作反馈**：让用户知道手势被识别
3. **设置合理阈值**：避免误触发
4. **考虑边界情况**：如快速滑动、连续操作
5. **保持一致性**：同类型操作使用相同手势
