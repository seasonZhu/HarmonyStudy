## 二、接口签名

### 2.1 签名机制

每个 HTTP 请求都包含签名相关 headers：

| Header | 说明 |
|--------|------|
| X-App-Id | 应用标识 |
| X-Timestamp | 时间戳（毫秒） |
| X-Nonce | 随机数 |
| X-Signature | 签名 |

### 2.2 签名算法

```
signature = SHA256(appId + timestamp + nonce + secretKey + sortedParams)
```

### 2.3 签名拦截器实现

```typescript
class SignInterceptor implements AxiosClientRequestInterceptor {
  private static readonly APP_ID = 'HarmonyStudy'

  onFulfilled = (config: InternalAxiosRequestConfig): InternalAxiosRequestConfig => {
    const timestamp = Date.now().toString()
    const nonce = CryptoUtil.generateUUID()

    // 设置基础 headers
    config.headers['X-App-Id'] = SignInterceptor.APP_ID
    config.headers['X-Timestamp'] = timestamp
    config.headers['X-Nonce'] = nonce

    // 计算签名
    const signature = this.generateSignature(
      SignInterceptor.APP_ID,
      timestamp,
      nonce,
      config.params
    )
    config.headers['X-Signature'] = signature

    return config
  }

  private generateSignature(
    appId: string,
    timestamp: string,
    nonce: string,
    params?: object
  ): string {
    const paramsString = params ? this.sortParams(params) : ''
    const signSource = `${appId}${timestamp}${nonce}${SIGN_SECRET_KEY}${paramsString}`
    return CryptoUtil.sha256(signSource)
  }

  private sortParams(params: object): string {
    const keys = Object.keys(params).sort()
    return keys.map(key => `${key}=${(params as any)[key]}`).join('&')
  }
}
```

### 2.4 服务器端验证

服务端需要对签名进行验证：

```typescript
function verifySignature(
  appId: string,
  timestamp: string,
  nonce: string,
  signature: string,
  params?: object
): boolean {
  // 1. 验证时间戳（5分钟内的请求才有效）
  const now = Date.now()
  const diff = now - parseInt(timestamp)
  if (diff > 5 * 60 * 1000) {
    return false  // 请求过期
  }

  // 2. 验证签名
  const expectedSignature = SHA256(appId + timestamp + nonce + SECRET_KEY + sortedParams)
  return signature === expectedSignature
}
```

## 三、敏感数据加密

### 3.1 加密工具类

项目提供了完整的加密工具类 `CryptoUtil`：

```typescript
export class CryptoUtil {
  // Base64 编码/解码
  static base64Encode(data: Uint8Array): string
  static base64Decode(encoded: string): Uint8Array

  // SHA 哈希
  static sha256(data: string): string

  // AES 加解密
  static async aesEncrypt(plainText: string, key: string): Promise<CryptoResult>
  static async aesDecrypt(encryptedText: string, key: string): Promise<CryptoResult>

  // 便捷方法
  static generateKey(length: number = 32): string
  static generateUUID(): string

```

### 3.2 Token 加密存储

```typescript
class SecureStorage {
  private static readonly KEY_TOKEN = 'secure_token'
  private static readonly KEY_ENCRYPTION = 'encryption_key'

  /**
   * 安全存储 Token
   */
  static async saveToken(token: string): Promise<void> {
    // 获取或生成加密密钥
    let encryptionKey = AppStorage.get<string>(SecureStorage.KEY_ENCRYPTION)
    if (!encryptionKey) {
      encryptionKey = CryptoUtil.generateKey(32)
      AppStorage.set(SecureStorage.KEY_ENCRYPTION, encryptionKey)
    }

    // 加密 Token
    const encrypted = await CryptoUtil.aesEncrypt(token, encryptionKey)
    if (encrypted.success) {
      // 存储加密后的 Token
      AppStorage.set(SecureStorage.KEY_TOKEN, encrypted.data)
    }
  }

  /**
   * 获取 Token
   */
  static async getToken(): Promise<string | null> {
    const encryptionKey = AppStorage.get<string>(SecureStorage.KEY_ENCRYPTION)
    const encrypted = AppStorage.get<string>(SecureStorage.KEY_TOKEN)

    if (!encryptionKey || !encrypted) {
      return null
    }

    const decrypted = await CryptoUtil.aesDecrypt(encrypted, encryptionKey)
    return decrypted.success ? decrypted.data : null
  }
}
```

### 3.3 Cookie 加密

```typescript
class SecureCookieManager {
  private static readonly COOKIE_KEY = 'secure_cookie'

  /**
   * 安全存储 Cookie
   */
  static async saveCookie(cookie: string): Promise<void> {
    const key = CryptoUtil.generateKey(32)
    const encrypted = await CryptoUtil.aesEncrypt(cookie, key)

    if (encrypted.success) {
      // 同时存储加密后的 cookie 和密钥
      AppStorage.set(SecureCookieManager.COOKIE_KEY, encrypted.data)
      AppStorage.set('cookie_key', key)
    }
  }

  /**
   * 获取 Cookie
   */
  static async getCookie(): Promise<string | null> {
    const encrypted = AppStorage.get<string>(SecureCookieManager.COOKIE_KEY)
    const key = AppStorage.get<string>('cookie_key')

    if (!encrypted || !key) {
      return null
    }

    const decrypted = await CryptoUtil.aesDecrypt(encrypted, key)
    return decrypted.success ? decrypted.data : null
  }
}
```

## 四、数据脱敏

### 4.1 脱敏拦截器

```typescript
class DesensitizeInterceptor implements AxiosClientRequestInterceptor {
  // 需要脱敏的字段
  private static readonly SENSITIVE_FIELDS = [
    'phone', 'phoneNumber', 'idCard', 'email', 'password'
  ]

  /**
   * 脱敏手机号
   */
  private desensitizePhone(phone: string): string {
    if (!phone || phone.length < 7) return phone
    return phone.substring(0, 3) + '****' + phone.substring(phone.length - 4)
  }

  /**
   * 脱敏邮箱
   */
  private desensitizeEmail(email: string): string {
    if (!email || !email.includes('@')) return email
    const [username, domain] = email.split('@')
    if (username.length <= 2) {
      return username[0] + '***@' + domain
    }
    return username[0] + '***' + username[username.length - 1] + '@' + domain
  }

  /**
   * 脱敏身份证
   */
  private desensitizeIdCard(idCard: string): string {
    if (!idCard || idCard.length < 10) return idCard
    return idCard.substring(0, 6) + '********' + idCard.substring(idCard.length - 4)
  }
}
```

### 4.2 脱敏字段映射

| 字段名 | 脱敏规则 | 示例 |
|--------|----------|------|
| phone | 中间4位隐藏 | 138****1234 |
| phoneNumber | 中间4位隐藏 | 138****1234 |
| idCard | 出生日期隐藏 | 110101****1234** |
| email | 用户名中间隐藏 | t***t@example.com |
| password | 替换为星号 | ****** |
| bankCard | 末4位显示 | ****1234 |
