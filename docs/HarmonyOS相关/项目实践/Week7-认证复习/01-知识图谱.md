## 二、ArkUI 状态管理

### 2.1 状态装饰器对比

| 装饰器 | 传播方向 | 使用场景 |
|--------|----------|----------|
| @State | 组件内部 | 组件私有状态 |
| @Prop | 父到子单向 | 从父组件接收只读数据 |
| @Link | 双向绑定 | 子组件修改影响父组件 |
| @Provide | 父到子孙单向 | 跨层级数据提供 |
| @Consume | 接收Provide | 响应 @Provide 数据 |
| @ObjectLink | 双向绑定 | 嵌套对象/数组观察 |
| @Observed | 类级别 | 标记被观察的类 |

### 2.2 AppStorage vs LocalStorage

| 特性 | AppStorage | LocalStorage |
|------|------------|--------------|
| 作用域 | 应用全局 | 页面级 |
| 生命周期 | 应用周期 | 页面周期 |
| 共享性 | 多页面共享 | 页面私有 |
| 使用场景 | 用户偏好、全局状态 | 页面私有数据 |

### 2.3 状态管理选择

```typescript
// 组件私有状态
@State counter: number = 0

// 父组件传递（只读）
@Prop title: string

// 双向绑定
@Link counter: number

// 嵌套对象观察
@Observed
class Article {
  title: string
  isCollected: boolean
}

@ObjectLink article: Article
```

## 三、生命周期

### 3.1 Ability 生命周期

```
onCreate() → onWindowStageCreate() → [前台运行] → onWindowStageDestroy() → onDestroy()
                      ↓
              onForeground() ←→ onBackground()
```

| 生命周期 | 说明 |
|----------|------|
| onCreate | Ability 创建时调用 |
| onWindowStageCreate | 窗口创建时调用 |
| onForeground | 应用进入前台 |
| onBackground | 应用进入后台 |
| onWindowStageDestroy | 窗口销毁时调用 |
| onDestroy | Ability 销毁时调用 |

### 3.2 页面生命周期

```
aboutToAppear() → build() → onPageShow() → [页面可见] → onPageHide() → aboutToDisappear()
```

| 生命周期 | 说明 |
|----------|------|
| aboutToAppear | 即将显示（可调用 setState） |
| build | 构建 UI（禁止调用 setState） |
| onPageShow | 页面显示 |
| onPageHide | 页面隐藏 |
| aboutToDisappear | 即将消失（清理定时器等） |

## 四、网络请求

### 4.1 拦截器执行顺序

```
请求发送
    │
    ▼
请求拦截器1（按注册顺序）
    │
    ▼
请求拦截器2
    │
    ▼
... (所有请求拦截器)
    │
    ▼
发送请求
    │
    ▼
接收响应
    │
    ▼
响应拦截器1（按注册顺序倒序）
    │
    ▼
响应拦截器2
    │
    ▼
... (所有响应拦截器)
    │
    ▼
返回数据
```

### 4.2 缓存策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| NO_CACHE | 不缓存 | 搜索结果 |
| CACHE_FIRST | 缓存优先 | 文章列表 |
| NETWORK_FIRST | 网络优先 | 收藏数据 |
| STALE_WHILE_REVALIDATE | 后台更新 | Banner |

## 五、分布式能力

### 5.1 迁移 vs 流转

| 特性 | 迁移 (Migration) | 流转 (Continuation) |
|------|------------------|---------------------|
| 数据量 | 支持完整数据迁移 | 仅页面状态 |
| 目标设备 | 任意可信设备 | 同一应用实例 |
| 实现方式 | continueMission | 页面状态接续 |
| 场景 | 断点续传 | 继续操作 |

### 5.2 设备类型

| 1 | 手机 |
| 2 | 平板 |
| 3 | PC |
| 4 | TV |

| 6 | 眼镜 |
