## 一、概述

路由守卫是路由系统的重要组成部分，用于在路由跳转前进行权限验证、业务校验等逻辑。本文档设计一套完整的路由守卫机制，增强现有 Router 的功能。

### 1.1 现有问题

- 登录验证逻辑分散在 `pushWithLogin` 方法中
- 缺少统一的守卫注册和管理机制
- 无法支持基于角色、权限的访问控制

### 1.2 设计目标

1. **统一入口**：所有路由跳转经过守卫检查
2. **可扩展**：支持多种类型的守卫（登录、角色、权限）
3. **可配置**：守卫可以按页面注册，灵活控制
4. **易使用**：提供简洁的 API

export enum GuardType {

```typescript
/**
 * 守卫结果

export interface GuardResult {
  /** 是否允许通过 */
  allow: boolean
  /** 拒绝时重定向的目标页面 */
  redirect?: string

  reason?: string
}
```

### 2.3 守卫接口

```typescript
/**
 * 路由守卫接口
 */
export interface RouteGuard {
  /** 守卫类型 */
  readonly type: GuardType
  /** 守卫名称 */
  readonly name: string
  /** 守卫优先级（数值越小越先执行） */
  readonly priority: number
  /** 适用页面列表（空数组表示所有页面） */
  readonly applyPages: string[]

  /**
   * 执行守卫检查
   * @param to 目标页面
   * @param from 来源页面
   * @returns 守卫结果
   */
  check(to: string, from: string): GuardResult
}
```

## 三、预定义守卫实现

### 3.1 登录守卫 (LoginGuard)

检查用户是否已登录，未登录时重定向到登录页。

```typescript
export class LoginGuard implements RouteGuard {
  readonly type = GuardType.LOGIN
  readonly name = 'LoginGuard'
  readonly priority = 1
  readonly applyPages: string[] = [] // 空数组表示所有页面

  check(to: string, from: string): GuardResult {
    const isLoggedIn = AccountManager.shared().isLogin()

    if (isLoggedIn) {
      return { allow: true }
    }

    return {
      allow: false,
      redirect: PagesConstant.Login,
      reason: '请先登录'
    }
  }
}
```

### 3.2 角色守卫 (RoleGuard)

检查用户是否具有特定角色。

```typescript
export class RoleGuard implements RouteGuard {
  readonly type = GuardType.ROLE
  readonly name = 'RoleGuard'
  readonly priority = 2
  /** 需要特定角色的页面列表 */
  readonly applyPages: string[] = []
  /** 允许的角色列表 */
  readonly allowedRoles: string[] = []

  check(to: string, from: string): GuardResult {
    const loginModel = AccountManager.shared().loginModel

    if (!loginModel) {
      return {
        allow: false,
        redirect: PagesConstant.Login,
        reason: '请先登录'
      }
    }

    // 如果没有配置允许角色，默认通过
    if (this.allowedRoles.length === 0) {
      return { allow: true }
    }

    // 检查用户角色（根据实际数据结构实现）
    const userRole = loginModel.role
    if (this.allowedRoles.includes(userRole)) {
      return { allow: true }
    }

    return {
      allow: false,
      reason: '您没有访问该页面的权限'
    }
  }
}
```

### 3.3 权限守卫 (AuthGuard)

检查用户是否具有特定权限。

```typescript
export class Permission {
  static readonly VIEW_COIN = 'view_coin'
  static readonly EDIT_COLLECTION = 'edit_collection'
  static readonly VIEW_STATS = 'view_stats'
}

export class AuthGuard implements RouteGuard {
  readonly type = GuardType.AUTH
  readonly name = 'AuthGuard'
  readonly priority = 3
  /** 需要特定权限的页面 */
  readonly applyPages: string[] = []
  /** 需要的权限列表 */
  readonly requiredPermissions: string[] = []

  check(to: string, from: string): GuardResult {
    const loginModel = AccountManager.shared().loginModel

    if (!loginModel) {
      return {
        allow: false,
        redirect: PagesConstant.Login,
        reason: '请先登录'
      }
    }

    // 如果没有配置权限要求，默认通过
    if (this.requiredPermissions.length === 0) {
      return { allow: true }
    }

    // 检查用户权限（根据实际数据结构实现）
    const userPermissions = loginModel.permissions || []
    const hasPermission = this.requiredPermissions.every(p => userPermissions.includes(p))

    if (hasPermission) {
      return { allow: true }
    }

    return {
      allow: false,
      reason: '您没有执行该操作的权限'
    }
  }
}
```

## 四、守卫注册与执行

### 4.1 守卫管理器

```typescript
/**
 * 守卫管理器
 */
export class GuardManager {
  private static guards: RouteGuard[] = []

  /**
   * 注册守卫
   */
  static register(guard: RouteGuard): void {
    this.guards.push(guard)
    // 按优先级排序
    this.guards.sort((a, b) => a.priority - b.priority)
  }

  /**
   * 执行所有守卫检查
   */
  static async execute(to: string, from: string): Promise<GuardResult> {
    for (const guard of this.guards) {
      // 检查守卫是否适用于目标页面
      if (!guard.check.apply(guard, [to, from]).allow) {
        // 空数组表示适用于所有页面
        if (guard.applyPages.length === 0 || guard.applyPages.includes(to)) {
          const result = guard.check(to, from)
          if (!result.allow) {
            return result
          }
        }
      }
    }
    return { allow: true }
  }
}
```

### 4.2 守卫执行流程

```
路由跳转请求
     │
     ▼
┌─────────────┐
│ 守卫管理器  │ ◄── 注册的守卫列表
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 按优先级    │ ──► 执行守卫1 ──► 拒绝？──► 返回重定向
│ 排序遍历    │       │
└──────┬──────┘       │ 通过
       │              ▼
       │       ┌─────────────┐
       │       │ 执行守卫2   │ ──► ...
       │       └─────────────┘
       │
       ▼
  全部通过
     │
     ▼
 执行路由跳转
```

## 六、Router 增强

### 6.1 新增方法

```typescript
export class Router {
  // ... 现有方法 ...

  // ==================== 守卫相关方法 ====================

  /**
   * 注册路由守卫
   */
  static registerGuard(guard: RouteGuard): void {
    GuardManager.register(guard)
  }

  /**
   * 批量注册守卫
   */
  static registerGuards(guards: RouteGuard[]): void {
    guards.forEach(guard => GuardManager.register(guard))
  }

  /**
   * 安全的路由跳转（经过守卫检查）
   */
  static safePush<T = object>(url: string, params?: T): void {
    const result = GuardManager.execute(url, router.getState().pageUrl)

    if (!result.allow) {
      // 重定向到指定页面
      if (result.redirect) {
        AppStorage.setOrCreate('afterLoginTarget', { url, params })
        Router.push(result.redirect)
      }
      return
    }

    Router.push(url, params)
  }

  /**
   * 带守卫检查的需要登录跳转
   * @deprecated 请使用 safePush 替代
   */
  static pushWithLogin<T = object>(url: string, params?: T): void {
    if (AccountManager.shared().isLogin()) {
      Router.push<T>(url, params)
    } else {
      AppStorage.setOrCreate('afterLoginTarget', { url, params })
      Router.toLogin()
    }
  }
}
```

### 6.2 使用示例

```typescript
// 初始化时注册守卫
Router.registerGuards([
  new LoginGuard(),           // 所有页面需要登录检查
  new RoleGuard(['AdminPage'], ['admin']),  // 管理员页面
  new AuthGuard(['MyCoin'], [Permission.VIEW_COIN])  // 积分页面需要查看积分权限
])

// 安全跳转（自动进行守卫检查）
Router.safePush(PagesConstant.MyCoin)

// 需要登录的跳转
Router.pushWithLogin(PagesConstant.MyCollect)
```
