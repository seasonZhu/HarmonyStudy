## 一、概述

本文档分析 HarmonyStudy 项目中可抽离为工具类、供后续项目直接复用的代码模块。

### 分析原则
- **SOLID 原则**：单一职责、开闭原则、依赖倒置
- **DRY 原则**：不重复造轮子
- **KISS 原则**：简单即可靠
- **YAGNI 原则**：仅抽取明确需要的

## 三、工具类详细说明

### 3.1 ToastUtil - 提示工具类

**文件**: `utils/ToastUtil.ets`

**功能特性**:
- 支持 5 种提示类型：success / error / info / warning / loading
- 统一调用入口：`ToastUtil.success()`, `ToastUtil.error()` 等
- 支持自定义配置：显示时长、位置等

**使用示例**:
```typescript
// 成功提示
ToastUtil.success('操作成功');

// 错误提示
ToastUtil.error('网络请求失败');

// 自定义提示
ToastUtil.show({ message: '自定义消息', duration: 3000 });
```

---

### 3.2 ErrorHandler - 错误处理工具

**文件**: `utils/ErrorHandler.ets`

**功能特性**:
- 统一错误类型：NETWORK / SERVER / CLIENT / UNKNOWN
- 自动日志记录
- 异步任务包装，自动错误处理
- 错误类型判断方法

**使用示例**:
```typescript
// 处理错误
ErrorHandler.handle(error, '操作失败，请稍后重试');

// 包装异步任务
const result = await ErrorHandler.wrap(someAsyncTask(), '加载失败');

// 判断错误类型
if (ErrorHandler.isNetworkError(appError)) {
  // 处理网络错误
}
```

---

### 3.3 LoadingDialogHelper - 加载对话框

**文件**: `utils/LoadingDialogHelper.ets`

**功能特性**:
- 全局单例模式
- 支持自动显示/隐藏
- `wrap()` 方法自动管理加载状态

**使用示例**:
```typescript
// 在 EntryAbility 中初始化
LoadingDialogHelper.init(windowStage)

// 基本用法
LoadingDialogHelper.show('加载中...')
await someApi()
LoadingDialogHelper.hide()

// 使用 wrap 自动管理
await LoadingDialogHelper.wrap(someApi(), '加载中...')
```

---

### 3.4 Router - 路由工具类

**文件**: `router/Router.ets`

**功能特性**:
- 类型安全的路由跳转
- 统一的参数获取
- 登录守卫集成
- 路由守卫框架支持

**使用示例**:
```typescript
// 简单跳转
Router.push('pages/Home')

// 带参数跳转
Router.push('pages/Detail', { id: '123' })

// 获取参数
const params = Router.getParams<WebLink>()

// 需要登录的跳转
Router.pushWithLogin('pages/MyCollect')

// 安全跳转（经过守卫检查）
Router.safePush('pages/MyCoin')
```

---

### 3.5 GuardManager - 路由守卫管理

**文件**: `router/guards/GuardManager.ets`

**功能特性**:
- 支持多个守卫注册
- 按优先级执行
- 守卫结果：允许/拒绝 + 重定向

**使用示例**:
```typescript
// 注册守卫
GuardManager.register(new LoginGuard())

// 执行守卫检查
const result = GuardManager.execute('pages/MyCoin', 'pages/Home')
if (!result.allow) {
  // 重定向到登录页
}
```

### 3.6 CryptoUtil - 加密工具类

**文件**: `utils/CryptoUtil.ets`

**功能特性**:
- AES 加密/解密

- Base64 编码/解码

**使用示例**:


### 3.7 HttpCacheManager - HTTP缓存管理

**文件**: `httpRequest/cache/HttpCacheManager.ets`

**功能特性**:
- 支持 6 种缓存策略
- 内存 + 磁盘双层缓存
- 缓存 key 自动生成
- 缓存过期自动清除

**使用示例**:
```typescript
// 获取缓存实例
const cache = HttpCacheManager.getInstance()

// 设置缓存
cache.set('article_list', data, { strategy: CacheStrategy.CACHE_FIRST, maxAge: 300 })

// 获取缓存
const data = cache.get('article_list')

// 清除缓存
cache.remove('article_list')
cache.clear()
```

---

### 3.8 CacheStrategy - 缓存策略

**文件**: `httpRequest/cache/CacheStrategy.ets`

**策略类型**:

| 策略 | 说明 |
|------|------|
| `NO_CACHE` | 不缓存，每次从网络获取 |
| `MEMORY_ONLY` | 仅内存缓存，关闭应用后失效 |
| `DISK_ONLY` | 仅磁盘缓存 |
| `CACHE_FIRST` | 缓存优先，失败时请求网络 |
| `NETWORK_FIRST` | 网络优先，失败时使用缓存 |
| `STALE_WHILE_REVALIDATE` | 使用缓存同时后台更新 |

## 五、改造建议

### 5.1 Router 依赖抽象

**问题**: `Router` 直接依赖 `PagesConstant`

**改造方案**: 将页面路径改为泛型参数传入

```typescript
// 改造后
export class Router {
  static push<T = object>(url: string, params?: T): void {
    router.push({ url, params })
  }
}

// 使用时直接传入字符串
Router.push('pages/Home')
```

### 5.2 LoginGuard 依赖抽象

**问题**: `LoginGuard` 直接依赖 `AccountManager`

**改造方案**: 通过构造函数注入账户检查函数

```typescript
// 改造后
export class LoginGuard implements RouteGuard {
  constructor(private checkLogin: () => boolean) {
    this.checkLogin = checkLogin
  }

  check(to: string, from: string): GuardResult {
    if (this.checkLogin()) {
      return { allow: true }
    }
    return { allow: false, redirect: 'pages/Login', reason: '请先登录' }
  }
}

// 使用时注入
GuardManager.register(new LoginGuard(() => AccountManager.shared().isLogin()))
```
