## 1. 跨设备迁移概述

### 1.1 什么是跨设备迁移

跨设备迁移（Continuation）是指将当前设备上的任务（包括页面状态、业务数据）迁移到另一台设备上继续执行，实现**任务接续**。

```
┌─────────┐   开始阅读文章   ┌─────────┐   迁移完成   ┌─────────┐
│  手机   │ ──────────────► │  断开   │ ──────────► │  平板   │
│         │                 │         │             │         │
│ 阅读进度 │                 │         │             │ 继续阅读 │
│   50%   │                 │   --    │             │   50%   │
└─────────┘                 └─────────┘             └─────────┘
```

### 1.2 迁移 vs 流转 vs 分布式调度

| 特性 | 跨设备迁移 | 流转 | 分布式调度 |
|-----|----------|-----|-----------|
| **数据** | 完整迁移 | 轻量同步 | 任务分发 |
| **场景** | 继续任务 | 内容共享 | 算力协同 |
| **交互** | 用户感知 | 可选通知 | 后台执行 |
| **数据量** | < 1MB | < 100KB | 无限制 |

## 3. WantAgent 迁移能力

### 3.1 核心 API

| API | 功能 | 所属模块 |
|-----|------|---------|
| `wantAgent.getWantAgent()` | 创建 WantAgent | @kit.AbilityKit |
| `continuationManager.registerContinuation()` | 注册迁移监听 | @kit.AbilityKit |
| `continuationManager.updateContinuationState()` | 更新迁移状态 | @kit.AbilityKit |

### 3.2 代码示例

```typescript
import { continuationManager } from '@kit.AbilityKit';
import { BusinessError } from '@kit.BasicServicesKit';

// 迁移状态枚举
enum ContinuationState {
  LOCAL_RUNNING = 0,      // 本地运行中
  REMOTE_RUNNING = 1,     // 远端运行中
  REMOTE_CANCELED = 2,    // 远端已取消
  LOCAL_CANCELED = 3,     // 本地已取消
}

// 1. 注册迁移监听
function registerContinuation(): void {
  let callback: continuationManager.ContinuationCallback = {
    onContinue(want: Want): void {
      // 对方设备请求迁移，数据序列化到 want 中
      AppLog.info('收到迁移请求');
    },
    onComplete(): void {
      AppLog.info('迁移完成');
    },
    onRemoteCanceled(reason: string): void {
      AppLog.warn('迁移被取消: %{public}s', reason);
    }
  };

  continuationManager.registerContinuation(callback, (err: BusinessError) => {
    if (err.code) {
      AppLog.error('注册迁移监听失败: %{public}s', JSON.stringify(err));
    } else {
      AppLog.info('迁移监听注册成功');
    }
  });
}
```

// 发起迁移
function startMigration(deviceId: string, data: MigrationData): void {
  let want: Want = {
    deviceId: deviceId,
    abilityName: 'EntryAbility',
    parameters: {
      '迁徙数据': JSON.stringify(data)
    }

      return;
    }
    continuationManager.startContinuation(agent);
  });
}

## 5. 调试要点

### 5.1 DevEco Studio 多设备模拟

1. **设备管理器**：使用 Tools -> Device Manager 添加模拟设备
2. **多设备调试**：连接多台真机或使用模拟器组合
3. **分布式模拟**：部分能力支持模拟器测试

### 5.2 迁移失败常见原因

| 错误 | 原因 | 解决方案 |
|-----|------|---------|
| 设备不在线 | 目标设备未连接 | 确保设备在同一网络 |
| 迁移被拒绝 | 用户取消授权 | 重新发起并确认授权 |
| 数据超限 | 迁移数据 > 1MB | 精简迁移数据 |
| 设备不兼容 | 设备不支持迁移 | 检查设备能力 |

### 5.3 数据序列化注意事项

```typescript
// 推荐：使用 JSON 序列化
const migrationData = JSON.stringify({
  articleId: '12345',
  readProgress: 50
});

// 不推荐：直接传递复杂对象
// 跨设备传输可能丢失对象原型
```
