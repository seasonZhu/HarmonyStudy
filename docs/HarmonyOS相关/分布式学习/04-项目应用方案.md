### 2.1 方案 A：收藏跨设备同步

#### 2.1.1 场景描述

用户在同一账号下，希望在手机端收藏的文章能够自动同步到平板端，实现多设备收藏共享。

#### 2.1.2 技术方案

```
┌─────────┐  收藏操作   ┌─────────┐  HTTP同步  ┌─────────┐
│  手机   │ ─────────► │ 服务器  │ ─────────► │  平板   │
│         │            │         │ ◄───────── │         │
│ 收藏列表│            │ 收藏API │   查询收藏  │ 收藏列表│
└─────────┘            └─────────┘            └─────────┘
```

#### 2.1.3 实现设计

```typescript
// 收藏同步服务
class CollectSyncService {
  // 当前设备收藏列表
  private localCollects: string[] = [];
  // 同步状态
  private syncState: 'idle' | 'syncing' | 'error' = 'idle';

  /**
   * 同步收藏列表
   */
  async syncCollects(): Promise<void> {
    this.syncState = 'syncing';

    try {
      // 1. 从服务器获取最新收藏
      const serverCollects = await CollectModel.getRemoteCollects();

      // 2. 合并本地和服务器数据
      const merged = this.mergeCollects(this.localCollects, serverCollects);

      // 3. 更新本地列表
      this.localCollects = merged;

      // 4. 如果有变化，上报服务器
      await this.reportToServer(merged);

      this.syncState = 'idle';
    } catch (error) {
      this.syncState = 'error';
      console.error('收藏同步失败:', error);
    }
  }

  /**
   * 合并收藏列表
   *
   * 策略：服务器优先（用户可能在其他设备收藏）
   */
  private mergeCollects(local: string[], server: string[]): string[] {
    const combined = new Set([...server, ...local]);
    return Array.from(combined);
  }

  /**
   * 上报收藏到服务器
   */
  private async reportToServer(collects: string[]): Promise<void> {
    // 通过 HTTP API 上报
  }
}
```

### 2.2 方案 B：阅读进度同步

#### 2.2.1 场景描述

用户在不同设备阅读文章时，能够自动同步阅读进度，换设备后从上次位置继续阅读。

#### 2.2.2 技术方案

```
┌─────────┐  阅读文章   ┌─────────┐  上报进度  ┌─────────┐
│  手机   │ ─────────► │ 服务器  │ ─────────► │  平板   │
│         │            │         │ ◄───────── │         │
│ 阅读65% │            │ 进度API │   获取进度  │ 打开文章│
└─────────┘            └─────────┘   显示70%  │ 从70%开始│
```

#### 2.2.3 实现设计

```typescript
// 阅读进度服务
class ReadingProgressService {
  // 进度上报防抖
  private reportDebounce: number = 0;

  /**
   * 更新阅读进度
   *
   * @param articleId 文章ID
   * @param progress 进度百分比 (0-100)
   */
  async updateProgress(articleId: string, progress: number): void {
    // 防抖处理，5秒内不重复上报
    if (this.reportDebounce > 0) {
      return;
    }
    this.reportDebounce = 5000;

    try {
      await ReadingProgressApi.reportProgress({
        articleId,
        progress,
        timestamp: Date.now(),
        deviceId: this.getDeviceId()
      });
    } catch (error) {
      console.error('进度上报失败:', error);
    } finally {
      setTimeout(() => {
        this.reportDebounce = 0;
      }, 5000);
    }
  }

  /**
   * 获取远程进度
   */
  async getRemoteProgress(articleId: string): Promise<number> {
    try {
      const response = await ReadingProgressApi.getProgress(articleId);
      return response.progress || 0;
    } catch {
      return 0;
    }
  }

  /**
   * 检查是否需要同步进度
   */
  async checkAndSyncProgress(articleId: string): Promise<boolean> {
    const localProgress = this.getLocalProgress(articleId);
    const remoteProgress = await this.getRemoteProgress(articleId);

    // 如果远程进度比本地新，提示用户同步
    return remoteProgress > localProgress;
  }
}
```

### 2.3 方案 C：登录态跨设备共享

#### 2.3.1 场景描述

用户在一个设备登录后，其他设备能够自动获取登录态，无需重复登录。

#### 2.3.2 技术方案

```
┌─────────┐  扫码登录   ┌─────────┐  Token同步 ┌─────────┐
│  手机   │ ─────────► │  平板   │ ─────────► │   PC    │
│         │            │         │   加密传输  │         │
│ 已登录  │            │ 登录态  │ ◄───────── │ 已登录  │
└─────────┘            └─────────┘            └─────────┘
```

#### 2.3.3 实现设计

```typescript
// 登录态管理器
class LoginStateManager {
  private static readonly TOKEN_KEY = 'user_token';
  private static readonly USER_INFO_KEY = 'user_info';

  /**
   * 安全存储 Token
   */
  async saveLoginState(token: string, userInfo: UserInfo): Promise<void> {
    // 使用 CryptoUtil 加密 Token
    const encryptedToken = await CryptoUtil.aesEncrypt(token, this.getMasterKey());

    // 存储加密后的 Token
    await persistenceStorage.put(LoginStateManager.TOKEN_KEY, encryptedToken);
    await persistenceStorage.put(LoginStateManager.USER_INFO_KEY, JSON.stringify(userInfo));

    // 同步到其他设备
    await this.syncToOtherDevices(token, userInfo);
  }

  /**
   * 同步登录态到其他设备
   */
  private async syncToOtherDevices(token: string, userInfo: UserInfo): Promise<void> {
    // 使用分布式能力同步
    // 需要设备发现和授权
    const devices = await DeviceManager.getTrustedDevices();

    for (const device of devices) {
      if (device.isOnline) {
        await DistributedDataStore.put(device.deviceId, {
          token: token,  // 实际应加密
          userInfo: userInfo,
          timestamp: Date.now()
        });
      }
    }
  }

  /**
   * 获取登录态
   */
  async getLoginState(): Promise<LoginState | null> {
    try {
      const encryptedToken = await persistenceStorage.get(LoginStateManager.TOKEN_KEY) as string;
      if (!encryptedToken) return null;

      const token = await CryptoUtil.aesDecrypt(encryptedToken, this.getMasterKey());
      const userInfoStr = await persistenceStorage.get(LoginStateManager.USER_INFO_KEY) as string;
      const userInfo = JSON.parse(userInfoStr);

      return { token, userInfo };
    } catch {
      return null;
    }
  }
}
```

## 5. 技术风险

| 风险 | 影响 | 缓解措施 |
|-----|------|---------|
| 数据冲突 | 多设备同时修改 | 服务端时间戳仲裁 |
| 网络不稳定 | 同步失败 | 本地队列 + 重试 |
| Token 安全 | 泄露风险 | 加密存储 + KeyStore |
| 隐私合规 | 跨设备数据同步 | 用户授权 + 数据最小化 |
