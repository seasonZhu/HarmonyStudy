## 1. 分布式任务调度概述

### 1.1 什么是分布式任务调度

分布式任务调度是指将本地任务分发到远程设备上执行，或者多个设备协同完成同一任务。

```
┌─────────────────────────────────────────────────────────────┐
│                   分布式任务调度示意                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────┐                      ┌─────────┐             │
│   │  手机   │ ─── 任务A (60%) ───► │  平板   │             │
│   │  CPU 20%│                      │  CPU 80% │             │
│   └────┬────┘                      └────┬────┘             │
│        │                                  │                 │
│        │         协同处理                 │                 │
│        └──────────────►◄────────────────┘                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心 API

| API | 功能 | 所属模块 |
|-----|------|---------|
| `distributedMission.createMissionSession()` | 创建任务会话 | @kit.MDMKit |
| `distributedMission.startMission()` | 启动分布式任务 | @kit.MDMKit |
| `distributedMission.closeMissionSession()` | 关闭任务会话 | @kit.MDMKit |
| `distributedMission.onMissionSessionCallback()` | 会话回调 | @kit.MDMKit |

## 2. 任务调度场景设计

### 2.1 场景：手机任务流转到平板

**场景描述**：手机上正在进行复杂计算（如图片处理），可以将任务流转到平板执行，利用平板更强的算力。

**流程**：

```
┌─────────┐  创建会话  ┌─────────┐  启动任务  ┌─────────┐
│  手机   │ ─────────► │  会话   │ ────────► │  平板   │
│         │            │  管理   │           │         │
│ 发起方  │            │  中心   │           │ 执行方  │
│         │            │         │           │         │
│ 等待结果 │ ◄───────── │         │ ◄──────── │ 返回结果 │
└─────────┘            └─────────┘           └─────────┘
```

### 2.2 数据结构设计

```typescript
// 任务信息
interface TaskInfo {
  taskId: string;           // 任务唯一ID
  taskType: TaskType;       // 任务类型
  priority: number;         // 优先级
  params: TaskParams;       // 任务参数
  sourceDevice: string;     // 源设备ID

// 任务类型枚举

  COMPUTE = 'compute',       // 计算任务
```

## 3. API 使用详解

### 3.1 创建任务会话

```typescript
import { distributedMission } from '@kit.MDMKit';
import { BusinessError } from '@kit.BasicServicesKit';

// 创建任务会话
function createMissionSession(deviceId: string): void {
  let sessionInfo: distributedMission.MissionSessionInfo = {
    deviceId: deviceId,
    missionId: 0,  // 0 表示创建新会话
    want: {
      abilityName: 'EntryAbility',
      parameters: {
        'taskType': 'compute'
      }
    }
  };

  distributedMission.createMissionSession(sessionInfo, (err: BusinessError, sessionId: number) => {
    if (err.code) {
      console.error('创建会话失败: ' + err.message);
      return;
    }
    console.info('会话创建成功, ID: ' + sessionId);
    // 保存 sessionId 用于后续操作
  });
}
```

### 3.2 启动分布式任务

```typescript
// 启动任务
function startMission(sessionId: number, taskInfo: TaskInfo): void {
  distributedMission.startMission(sessionId, taskInfo, (err: BusinessError) => {
    if (err.code) {
      console.error('启动任务失败: ' + err.message);
      return;
    }
    console.info('任务启动成功');
  });
}
```

### 3.3 注册会话回调

```typescript
// 注册任务回调
function registerMissionCallback(sessionId: number): void {
  let callback: distributedMission.MissionSessionCallback = {
    onAcceptWant: (want: Want) => {
      // 对方设备接受任务
      console.info('设备接受任务');
      return 'success';
    },
    onMissionClosed: (missionId: number) => {
      // 任务结束
      console.info('任务关闭: ' + missionId);
    },
    onNotifyDeviceLevel: (level: number) => {
      // 设备等级变化通知
      console.info('设备等级: ' + level);
    }
  };

  distributedMission.onMissionSessionCallback(sessionId, callback);
}
```

## 4. 任务调度限制条件

### 4.1 设备限制

| 限制项 | 说明 |
|-------|------|
| **设备类型** | 必须是 HarmonyOS 设备 |
| **设备数量** | 单次最多 4 台设备协同 |
| **设备距离** | 建议在同一局域网内 |

### 4.2 数据限制

| 限制项 | 说明 |
|-------|------|
| **单次数据量** | 建议 < 10MB |
| **任务超时** | 默认 30 秒超时 |
| **并发数量** | 单设备最多 5 个并发任务 |

### 4.3 网络要求

- 需要稳定的网络连接
- 建议在同一 WiFi 热点下
- 蓝牙可作为发现协议，但传输用 WiFi

```typescript
// 任务调度 Demo 片段
import { distributedMission } from '@kit.MDMKit';

// 任务结果回调
interface TaskResult {
  taskId: string;
  success: boolean;
  result: string;
  costTime: number;
}

// 执行任务
async function executeRemoteTask(sessionId: number, task: TaskInfo): Promise<TaskResult> {
  return new Promise((resolve, reject) => {
    distributedMission.startMission(sessionId, task, (err: BusinessError) => {
      if (err.code) {
        reject(err);
        return;
      }

      // 模拟任务执行
      setTimeout(() => {
        resolve({
          taskId: task.taskId,
          success: true,
          result: '处理完成',
          costTime: 2000
        });
      }, 2000);
    });
  });
}
```

## 6. 与跨设备迁移的区别

| 特性 | 跨设备迁移 | 分布式任务调度 |
|-----|----------|--------------|
| **目标** | 继续任务 | 执行任务 |
| **数据量** | 页面状态 + 业务数据 | 任务参数 + 结果 |
| **交互方式** | 用户感知（可选） | 后台执行 |
| **典型场景** | 阅读接续、编辑接续 | 图片处理、视频解码 |
