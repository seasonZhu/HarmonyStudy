## 一、分布式架构概述

### 1.1 分布式软总线
- **定义**：设备间通信的基础能力，实现近场设备间的发现和连接
- **核心特性**：
  - 自动发现：设备自动发现无需手动配对
  - 零等待连接：基于 Wi-Fi Direct 或 Bluetooth 建立连接
  - 统一协议：屏蔽不同通信协议的差异

### 1.2 设备虚拟化
- **目的**：让应用可以像访问本地资源一样访问远程设备资源
- **能力**：
  - 跨设备相机：调用远处设备的摄像头
  - 跨设备屏幕：将在远处设备上显示内容
  - 跨设备音频：使用远处设备的扬声器或麦克风

### 1.3 数据同步
- **分布式数据库**：
  - 跨设备数据共享
  - 最终一致性
  - 支持结构化数据
- **与本地数据库区别**：
  - 本地数据库：单设备数据存储
  - 分布式数据库：多设备间数据同步

## 二、跨设备迁移

### 2.1 概念
跨设备迁移（Continuation）是指将应用在当前设备上的状态（UI 状态、业务数据）迁移到另一台设备上，让用户可以在新设备上继续操作。

### 2.2 迁移 vs 流转

| 特性 | 跨设备迁移 | 跨设备流转 |
|------|-----------|-----------|
| UI 是否迁移 | 是，完整迁移 | 否，纯任务流转 |
| 用户体验 | 连续性操作 | 后台任务执行 |
| 数据量 | KB 级别 | 大数据量 |
| 典型场景 | 文档编辑、视频播放 | 下载任务、文件传输 |

### 2.3 迁移时机
- 用户主动触发：拖拽图标到目标设备
- 系统建议：基于用户行为预测

### 2.4 迁移数据
- **WantAgent**：携带迁移信息
- **限制**：一般限制在 KB 级别
- **大数据处理**：通过分布式数据库中转

### 2.5 核心 API

```typescript
// 迁移回调
onContinue(wantAgent: WantAgent): void {
  // 迁移操作
}

// 恢复迁移
onContinueCallback(wantAgent: WantAgent): void {
  // 恢复操作
}
```

### 2.6 高频考点

1. **迁移是 UI + 状态一起迁移**
2. **迁移数据量有限制（KB 级）**
3. **迁移失败需要考虑回退机制**
4. **迁移适用于需要用户连续操作的场景**

## 三、分布式任务调度

### 3.1 概念
分布式任务调度允许应用在本地设备上启动远程设备的能力（Ability），实现跨设备协作。

### 3.2 使用场景
- 跨设备启动 Ability
- 任务会话管理
- 回调处理

### 3.3 与迁移的区别

| 场景 | 分布式任务调度 | 跨设备迁移 |
|------|--------------|-----------|
| 启动远程相机 | ✅ | ❌ |
| 继续编辑文档 | ❌ | ✅ |
| 后台下载 | ✅ | ❌ |

### 3.4 核心 API

```typescript
// 跨设备启动 Ability
startAbilityRemote(deviceId: string, want: Want): void

// 跨设备连接 ServiceAbility
connectAbilityRemote(deviceId: string, want: Want): void
```

## 四、超级终端概念

### 4.1 定义
超级终端是鸿蒙提出的分布式概念，将多个设备虚拟化为一个统一的终端设备。

### 4.2 特征
- **设备池化**：多个设备作为统一资源池
- **能力共享**：外设、网络、存储等资源共享
- **无缝体验**：用户无感知设备边界

## 五、自问自答

### Q1: 什么情况下使用跨设备迁移而不是分布式任务调度？

**A:**
- **跨设备迁移**：适用于需要用户连续操作场景
  - 示例：手机编辑文档迁移到平板继续编辑
  - 特点：UI + 状态一起迁移
- **分布式任务调度**：适用于后台独立执行场景
  - 示例：手机启动平板的相机进行拍照
  - 特点：纯任务流转，不涉及 UI

### Q2: 迁移的数据量有限制吗？

**A:**
- 有，一般限制在 **KB 级别**
- 大数据需要通过**分布式数据库**中转
- 设计时需要考虑数据压缩和分页

### Q3: 迁移失败如何处理？

**A:**
1. 做好迁移前的数据校验
2. 设计回退机制，保留本地数据
3. 记录迁移状态，支持重新迁移
4. 向用户反馈迁移结果

### Q4: 流转和迁移的本质区别是什么？

**A:**
- **流转**：纯任务级别的协同，不涉及 UI
- **迁移**：将完整的操作上下文（UI + 状态）迁移到新设备

### Q5: 分布式数据库和本地数据库有什么区别？

**A:**
- **本地数据库**：单设备使用，无法跨设备共享
- **分布式数据库**：多设备间自动同步，支持结构化数据
- 鸿蒙使用 **rdb store** 支持分布式能力

## 六、关键概念速记

| 概念 | 速记 |
|------|------|
| 迁移 = | UI 迁移 + 状态迁移 |
| 流转 = | 纯任务流转，不迁移 UI |
| 迁移数据量 | KB 级别 |
| 分布式数据库 | rdb store |
| 设备发现 | 软总线自动发现 |
| 跨设备能力 | 需要 WantAgent |
