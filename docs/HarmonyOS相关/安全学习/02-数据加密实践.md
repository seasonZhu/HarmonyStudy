## 1. HarmonyOS 加密体系概述

### 1.1 加密框架组成

```
┌─────────────────────────────────────────────────────────────┐
│                  HarmonyOS 加密框架                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────────────┐      ┌─────────────────┐              │
│   │  cryptoFramework │      │     keyStore    │              │
│   │   (主要加密API)  │      │   (密钥存储)     │              │
│   └────────┬────────┘      └────────┬────────┘              │
│            │                          │                      │
│   ┌────────┴──────────────────────────┴────────┐            │
│   │              安全基础层                      │            │
│   │         (密钥管理、随机数生成)                │            │
│   └─────────────────────────────────────────────┘            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 支持的加密算法

| 类型 | 算法 | 说明 |
|-----|------|------|
| **对称加密** | AES、DES、3DES | 加解密使用相同密钥 |
| **非对称加密** | RSA、ECC | 公钥加密、私钥解密 |
| **散列算法** | MD5、SHA-256、SHA-512 | 单向哈希，不可逆 |
| **MAC** | HMAC | 带密钥的哈希 |
| **Base64** | - | 编码，非加密 |

  const options: huks.HuksParamSet = {
    properties: [
      { tag: huks.HuksTag.HUKS_TAG_ALGORITHM, value: huks.HuksKeyAlg.HUKS_ALG_AES },

## 3. 加密工具类设计

### 3.1 CryptoUtil 功能设计

```typescript
/**
 * CryptoUtil - 加密工具类
 *
 * 提供：
 * 1. AES 加密/解密
 * 2. SHA256 哈希
 * 3. Base64 编码/解码
 * 4. 密钥生成
 */
export class CryptoUtil {
  // AES 加密
  static async aesEncrypt(data: string, key: string): Promise<string>

  // AES 解密
  static async aesDecrypt(encrypted: string, key: string): Promise<string>

  // SHA256 哈希
  static sha256(data: string): string

  // Base64 编码
  static base64Encode(data: Uint8Array): string

  // Base64 解码
  static base64Decode(encoded: string): Uint8Array
}
```

### 3.2 使用示例

```typescript
import { CryptoUtil } from './CryptoUtil';

// 加密数据
const key = 'my-secret-key-123';
const original = 'Hello World';

const encrypted = await CryptoUtil.aesEncrypt(original, key);
console.info('加密后: ' + encrypted);

// 解密数据
const decrypted = await CryptoUtil.aesDecrypt(encrypted, key);
console.info('解密后: ' + decrypted);

// SHA256 哈希
const hash = CryptoUtil.sha256('password123');
console.info('哈希值: ' + hash);
```

## 4. 敏感数据加密方案

### 4.1 敏感数据分类

| 数据类型 | 敏感性 | 加密方案 | 存储位置 |
|---------|-------|---------|---------|
| 用户密码 | 高 | SHA256 哈希 | 服务端 |
| Token | 高 | AES 加密 | KeyStore |
| Cookie | 中 | AES 加密 | KeyStore |
| 用户信息 | 中 | AES 加密 | 分布式数据库 |
| 浏览历史 | 低 | 可选加密 | 本地存储 |

### 4.2 Token 安全方案

```typescript
/**
 * Token 安全管理方案
 */
class TokenManager {
  private static readonly KEY_ALIAS = 'user_token_key';
  private static readonly IV = 'fixed-iv-16bytes';  // 生产环境应随机

  /**
   * 安全存储 Token
   */
  static async saveToken(token: string): Promise<void> {
    // 使用 AES 加密
    const encrypted = await CryptoUtil.aesEncrypt(token, this.getMasterKey());
    // 存储到 KeyStore
    await this.storeToKeyStore(encrypted);
  }

  /**
   * 安全读取 Token
   */
  static async getToken(): Promise<string | null> {
    const encrypted = await this.readFromKeyStore();
    if (!encrypted) return null;
    return await CryptoUtil.aesDecrypt(encrypted, this.getMasterKey());
  }

  /**
   * 获取主密钥（实际应从 KeyStore 获取）
   */
  private static getMasterKey(): string {
    // 实际生产中应使用更安全的方式
    return 'master-key-from-keystore';
  }
}
```

### 4.3 密码加密方案

```typescript
/**
 * 密码加密方案
 *
 * 1. 不存储明文密码
 * 2. 使用 SHA256 哈希
 * 3. 添加盐值防止彩虹表攻击
 */
class PasswordCrypto {
  private static readonly SALT_LENGTH = 16;

  /**
   * 密码哈希
   */
  static hash(password: string, salt?: string): { hash: string; salt: string } {
    // 生成盐值
    const usedSalt = salt || this.generateSalt();
    // 拼接密码和盐值
    const combined = password + usedSalt;
    // SHA256 哈希
    const hash = CryptoUtil.sha256(combined);

    return {
      hash: hash,
      salt: usedSalt
    };
  }

  /**
   * 验证密码
   */
  static verify(password: string, hash: string, salt: string): boolean {
    const result = this.hash(password, salt);
    return result.hash === hash;
  }

  /**
   * 生成盐值
   */
  private static generateSalt(): string {
    const random = new Uint8Array(this.SALT_LENGTH);
    for (let i = 0; i < this.SALT_LENGTH; i++) {
      random[i] = Math.floor(Math.random() * 256);
    }
    return CryptoUtil.base64Encode(random);
  }
}
```

## 5. 安全存储建议

### 5.1 密钥存储层级

```
┌─────────────────────────────────────────────────────────────┐
│                    安全存储层级                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Level 1: 敏感数据加密                                       │
│  ├── AES 加密后存储                                          │
│  └── 密钥存储在 KeyStore                                    │
│                                                             │
│  Level 2: KeyStore 保护                                    │
│  ├── 使用设备绑定密钥                                        │
│  └── 用户认证后访问                                          │
│                                                             │
│  Level 3: 硬件级安全 (SE/TEE)                                │
│  └── 高敏感数据使用安全芯片                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 存储位置选择

| 数据类型 | 推荐存储 | 原因 |
|---------|---------|------|
| Token | KeyStore | 高安全性要求 |
| 用户信息 | 分布式数据库 | 需要跨设备同步 |
| 草稿数据 | 本地数据库 | 大量数据 |
| 设置项 | 用户首选项 | 轻量级数据 |

## 6. 注意事项

### 6.1 常见安全问题

| 问题 | 风险 | 解决方案 |
|-----|------|---------|
| 硬编码密钥 | 密钥泄露 | 使用 KeyStore |
| MD5 哈希 | 可被彩虹表破解 | 使用 SHA256 + 盐 |
| Base64 编码 | 非加密 | 仅用于数据格式转换 |
| ECB 模式 | 加密模式不安全 | 使用 GCM/CBC 模式 |

### 6.2 加密算法选择

| 场景 | 推荐算法 | 密钥长度 |
|-----|---------|---------|
| 数据加密 | AES-GCM | 128/256位 |
| 签名 | SHA256withRSA | 2048位 |
| 哈希 | SHA256 | - |
| HMAC | HMAC-SHA256 | 256位 |
