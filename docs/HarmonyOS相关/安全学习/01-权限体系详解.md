## 1. 权限分类概述

### 1.1 权限级别分类

HarmonyOS 将权限分为四个级别，从高到低：

| 级别 | 名称 | 申请方式 | 用户可控 | 示例 |
|-----|------|---------|---------|------|
| **Normal** | 正常权限 | 自动授予 | 否 | 网络、振动、屏幕旋转 |
| **Restricted** | 受限权限 | 需审核 | 部分 | 位置、相机、麦克风 |
| **Grantable** | 可授权权限 | 用户授权 | 是 | 存储、联系人、通话记录 |
| **System** | 系统权限 | 不允许三方 | 否 | 系统设置、账户管理 |

### 1.2 APL 等级说明

APL (Ability Privilege Level) 是应用的权限等级：

```
┌─────────────────────────────────────────────────────────────┐
│                    APL 等级层次                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   System ACL        ████████████████████████████  最高       │
│                                                             │
│   System Basic      ████████████████████                     │
│                                                             │
│   Normal            ████████████                             │
│                                                             │
│   APL_normal        ████                      最低          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**等级说明**：
- **APL_normal**：默认等级，可申请 Normal 权限
- **Normal**：可申请 Normal + Grantable 权限
- **System Basic**：可申请大部分受限权限
- **System ACL**：系统核心权限，仅系统应用

## 2. 权限申请流程

### 2.1 标准申请流程

```typescript
import { abilityAccessCtrl, bundleManager } from '@kit.AbilityKit';
import { BusinessError } from '@kit.BasicServicesKit';

/**
 * 权限申请标准流程
 */
async function requestPermission(permissionName: string): Promise<boolean> {
  // 1. 获取权限管理实例
  const atManager = abilityAccessCtrl.createAtManager();

  // 2. 获取应用 Bundle 信息
  const bundleInfo = await bundleManager.getBundleInfoForSelf(
    bundleManager.BundleFlag.GET_BUNDLE_INFO_WITH_APPLICATION
  );

  // 3. 检查是否已有权限
  const tokenId = bundleInfo.appInfo.accessTokenId;
  const grantStatus = atManager.checkAccessToken(tokenId, permissionName);

  if (grantStatus === abilityAccessCtrl.GrantStatus.PERMISSION_GRANTED) {
    console.info('权限已授予');
    return true;
  }

  // 4. 请求权限
  return new Promise((resolve) => {
    atManager.requestPermissionOnUser(
      permissionName,
      (err: BusinessError, result: abilityAccessCtrl.RequestResult) => {
        if (err.code) {
          console.error('权限申请失败: ' + err.message);
          resolve(false);
          return;
        }

        // 5. 处理授权结果
        if (result === abilityAccessCtrl GrantStatus.PERMISSION_GRANTED) {
          console.info('用户授予权限');
          resolve(true);
        } else {
          console.info('用户拒绝权限');
          resolve(false);
        }
      }
    );
  });
}
```

### 2.2 权限申请结果回调

```typescript
// 权限申请回调处理
function handlePermissionResult(requestCode: number, permissions: string[], results: number[]): void {
  for (let i = 0; i < permissions.length; i++) {
    if (results[i] === abilityAccessCtrl.GrantStatus.PERMISSION_GRANTED) {
      console.info('权限获取成功: ' + permissions[i]);
    } else {
      console.warn('权限被拒绝: ' + permissions[i]);
      // 可以引导用户去设置页面开启
    }
  }
}
```

## 6. 最佳实践

### 6.1 权限申请原则

1. **最小权限原则**：只申请功能必需的权限
2. **提前申请**：在需要权限的功能前申请
3. **渐进式申请**：不要一次性申请多个权限
4. **提供替代**：权限被拒绝时提供替代方案

### 6.2 权限被拒绝处理

```typescript
/**
 * 处理权限被拒绝的情况
 */
function handlePermissionDenied(permissionName: string): void {
  // 1. 判断是否需要解释
  const shouldExplain = canRequestPermission(permissionName);

  if (shouldExplain) {
    // 2. 显示解释对话框
    AlertDialog.show({
      title: '权限申请',
      message: '此功能需要' + getPermissionName(permissionName) + '权限，请授权',
      confirm: {
        value: '去设置',
        action: () => {
          // 3. 引导到设置页面
          openAppSettings();
        }
      },
      cancel: {
        value: '取消',
        action: () => {
          // 4. 关闭功能或提示
        }
      }
    });
  } else {
    // 直接提示用户
    promptAction.showToast({
      message: '缺少必要权限，功能无法使用'
    });
  }
}

/**
 * 打开应用设置页面
 */
function openAppSettings(): void {
  const context = getContext();
  const want = {
    bundleName: 'com.example.app',
    abilityName: 'EntryAbility',
    flags: wantConstant.Flags.ABILITY_FORM_SHOW_SETTINGS
  };

  startAbility(want).catch((err: BusinessError) => {
    console.error('打开设置失败: ' + err.message);
  });
}
```

## 7. 常见问题

### Q1: 权限申请时机？

**最佳时机**：
- 功能入口处申请（如点击拍照按钮）
- 应用首次启动时申请基础权限
- 避免在应用启动页申请

### Q2: 如何判断权限是否被永久拒绝？

```typescript
function isPermissionPermanentlyDenied(permissionName: string): boolean {
  const atManager = abilityAccessCtrl.createAtManager();
  // 如果用户在设置中关闭了权限，且选择了"不再询问"
  return !canRequestPermission(permissionName);
}
```

### Q3: 权限申请有次数限制吗？

- 用户拒绝一次后，下次还可以再申请
- 用户选择"不再询问"后，需要引导用户去设置开启
- 没有固定的申请次数限制
