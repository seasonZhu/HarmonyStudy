### 推荐学习路径

```
第一阶段：巩固基础
├── ArkUI 声明式开发深入
├── 状态管理高级用法
└── 网络封装最佳实践

第二阶段：强化弱项
├── 分布式能力专项
├── 性能优化实战
└── 安全机制理解

第三阶段：模拟练习
├── 官方题库练习
├── 模拟考试
└── 错题复习
```

### 关键考点提醒

**高频考点（必须掌握）：**
1. `@State` / `@Prop` / `@Link` 的区别和使用场景
2. `@Observed` / `@ObjectLink` 实现原理
3. BaseProvider 拦截器责任链模式
4. 启动优化：Splash 和 Ability 生命周期
5. 登录拦截和路由守卫实现

**易错考点：**
1. 状态装饰器的限制条件
2. ForEach 和 LazyForEach 的性能差异
3. 分布式任务调度的使用限制
4. 权限弹窗的时机和用户交互
