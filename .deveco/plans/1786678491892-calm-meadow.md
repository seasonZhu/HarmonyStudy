## Goal

优化 ProjectCell 和 ArticleCell 的视觉效果：图文排版协调、间距留白合理、具备卡片感和层次感、文字样式精致。

## Current State And Constraints

**ProjectCell 当前问题**：
1. 图文排版不协调：图片 `width("20%")` 比例偏小，`height(120)` 固定高度不适配
2. 间距不合理：外层 Column 无 padding，图文区 `padding(8)` 与 MetaRow 不统一
3. 缺少卡片感：无圆角、无阴影
4. 文字样式单调：分类标签无背景色，描述无行距

**ArticleCell 当前问题**（同步优化）：
1. 同样无卡片感：Column 无圆角无阴影无 padding
2. 标签样式单调：与 ProjectCell 相同问题
3. 间距不统一：标题区域 margin 与卡片边距不协调

**涉及文件**：
- [StyleConstants.ets](entry/src/main/ets/constants/StyleConstants.ets)
- [ArticleMetaRow.ets](entry/src/main/ets/views/ArticleMetaRow.ets)

## Design

### 1. StyleConstants — CardStyle 常量

```typescript
export class CardStyle {
  static readonly BORDER_RADIUS: number = 12
  static readonly INNER_PADDING: number = 12
  static readonly SHADOW_RADIUS: number = 4
  static readonly TAG_BORDER_RADIUS: number = 4
  static readonly TAG_PADDING_LEFT: number = 6
  static readonly TAG_PADDING_RIGHT: number = 6
  static readonly TAG_PADDING_TOP: number = 2
  static readonly TAG_PADDING_BOTTOM: number = 2
  static readonly TAG_FONT_SIZE: number = 11
}
```

### 2. ArticleMetaRow 样式优化

- 作者名 `.fontColor($r('app.color.text_primary'))`（加深，#333333）
- 时间 `.fontColor($r('app.color.text_tertiary'))`（变浅，#999999）
- 置顶/新/标签 加浅色背景药丸：
  - 置顶：红色文字 + `#FFEBEE` 浅红背景
  - 新：紫色文字 + `#F3E5F5` 浅紫背景
  - 标签：蓝色文字 + `#E3F2FD` 浅蓝背景
- 统一使用 CardStyle 常量

### 3. ProjectCell 布局重构

**卡片容器**：
```
Column() { ... }
  .width('100%')
  .backgroundColor($r('app.color.white'))
  .borderRadius(CardStyle.BORDER_RADIUS)
  .shadow({ radius: CardStyle.SHADOW_RADIUS, color: '#1A000000', offsetX: 0, offsetY: 1 })
  .padding(CardStyle.INNER_PADDING)
```

**图文区**：
- Row 替代 Flex，图片 `width(80) height(80) borderRadius(8)`，右侧 `margin({ left: 12 })`
- 文字区域 `layoutWeight(1)`，标题 maxLines=2，描述 maxLines=3 + `.lineHeight(18)`

**标签行**：使用 CardStyle 药丸常量 + 浅绿背景 `#E8F5E9`

### 4. ArticleCell 布局重构

**卡片容器**：同 ProjectCell 样式

**内容间距**：
- MetaRow 保持不变（已有 padding）
- 标题区 `.margin({ top: 4, bottom: 4 })` 缩小间距（卡片已有 padding 兜底）
- 底部标签行使用同样药丸样式 + 浅绿背景

## Risks And Compatibility

- `shadow` 修饰符 API 9+ 可用，需确认项目最低版本
- 图片 80vp 在 360dp 宽度占比约 22%，合理
- 列表间距需 List space 配合，卡片自身不加 margin
