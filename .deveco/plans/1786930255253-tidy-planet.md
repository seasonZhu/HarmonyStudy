# HarmonyStudy 模块化演进计划

## 目标

将 HarmonyStudy 项目从当前的混合架构演进为清晰的 MVVM + Repository 架构，统一网络层，提取通用组件为 HAR 包，提高代码的可维护性、可测试性和复用性。

## 当前状态分析

### 1. 网络层现状

**httpRequest 模块**（entry/src/main/ets/httpRequest/）：
- 基于 BaseProvider 抽象类，使用模板方法模式
- 已在项目中广泛使用（43处）
- 返回类型：`Promise<AxiosResponse<BaseResponse<T>>>`
- 功能：环境管理、拦截器、日志记录

**network 模块**（network/）：
- 基于 HttpClient 类，提供完整的 HTTP 客户端功能
- 已创建但未充分使用（仅7处）
- 返回类型：`Promise<ApiResponse<T>>`
- 功能：环境管理、拦截器、错误处理、重试机制、加载提示、日志记录

**对比结论**：
- network 模块功能更完善（错误处理、重试机制、加载提示）
- network 模块 API 更清晰（ApiResponse vs AxiosResponse）
- httpRequest 模块已稳定运行，但功能较弱

### 2. 架构现状

**当前架构**：
```
entry/
├── pages/          (23个页面，直接依赖 axios)
├── viewModel/      (10个ViewModel，返回 AxiosResponse)
├── model/          (11个数据模型)
├── views/          (12个组件，未提取)
├── httpRequest/    (旧网络封装)
└── network/        (新网络示例，未使用)
```

**问题**：
1. ViewModel 返回 AxiosResponse，暴露 HTTP 实现细节
2. Page 直接处理 HTTP 响应，职责不清
3. 通用组件未提取，难以复用
4. 存在两套网络封装，代码冗余

### 3. 模块依赖现状

```
entry → network (仅7处)
entry → Utils (3处)
entry → librarySDK (2处)
entry → @ohos/axios (43处，绕过 network 模块)
```

### 阶段二：渐进式迁移到 network 模块（3-5天）

#### 2.1 创建 Repository 层基础结构

**目标**：引入 Repository 层，隔离网络实现细节

**步骤**：
1. 创建 `entry/src/main/ets/repository/` 目录
2. 创建基础 Repository 接口和实现
3. 创建数据映射器（Mapper）

**目录结构**：
```
repository/
├── base/
│   └── BaseRepository.ets        # 基础Repository
├── ArticleRepository.ets         # 文章数据仓库
├── AuthRepository.ets            # 认证数据仓库
├── UserRepository.ets            # 用户数据仓库
└── mappers/
    ├── ArticleMapper.ets         # 文章数据映射
    └── UserMapper.ets            # 用户数据映射
```

**示例代码**：
```typescript
// repository/base/BaseRepository.ets
export abstract class BaseRepository {
  protected httpClient: HttpClient
  
  constructor() {
    this.httpClient = getHttpClient()
  }
  
  protected handleError(error: ApiError): void {
    // 统一错误处理
    ErrorHandler.handle(error)
  }
}

// repository/ArticleRepository.ets
export class ArticleRepository extends BaseRepository {
  async getArticleList(page: number): Promise<Article[]> {
    try {
      const response = await this.httpClient.get<PageModel<Article>>(
        ApiConstants.articleList(page)
      )
      return response.data.datas
    } catch (error) {
      this.handleError(error as ApiError)
      throw error
    }
  }
}
```

#### 2.2 迁移第一个 ViewModel（试点）

**目标**：选择一个简单的 ViewModel 进行迁移试点

**选择标准**：
- 功能简单，依赖少
- 有代表性（包含 GET/POST）
- 影响范围小

**推荐**：`RankViewModel.ets`（排行榜）

**迁移步骤**：
1. 创建 `RankRepository.ets`
2. 修改 `RankViewModel.ets`，使用 Repository
3. 修改 `Rank.ets` 页面，适配新的数据结构
4. 测试功能完整性

**迁移前后对比**：

**迁移前**：
```typescript
// RankViewModel.ets
import provider from '../httpRequest/Provider'

export class RankViewModel {
  async getRank(page: number): Promise<AxiosResponse<BaseResponse<PageModel<RankModel>>>> {
    return provider.get(ApiConstants.rank(page))
  }
}

// Rank.ets
const result = await this.viewModel.getRank(page)
const ranks = result.data.data.datas
```

**迁移后**：
```typescript
// repository/RankRepository.ets
export class RankRepository extends BaseRepository {
  async getRankList(page: number): Promise<RankModel[]> {
    const response = await this.httpClient.get<PageModel<RankModel>>(
      ApiConstants.rank(page)
    )
    return response.data.datas
  }
}

// RankViewModel.ets
export class RankViewModel {
  private rankRepo = new RankRepository()
  
  async getRank(page: number): Promise<RankModel[]> {
    return this.rankRepo.getRankList(page)
  }
}

// Rank.ets
const ranks = await this.viewModel.getRank(page)
```

**封装示例**：
```typescript
// components/ImageLoader.ets
import { ImageKnifeComponent } from '@ohos/imageknife'

@Component
export struct ImageLoader {
  @Prop src: string | Resource
  @Prop placeholder: Resource = $r('app.media.pic_image_placeholder')
  @Prop errorHolder: Resource = $r('app.media.pic_image_placeholder')
  @Prop objectFit: ImageFit = ImageFit.Cover
  
  build() {
    ImageKnifeComponent({
      imageKnifeOption: {
        loadSrc: this.src,
        placeholderSrc: this.placeholder,
        errorholderSrc: this.errorHolder,
        objectFit: this.objectFit
      }
    })
  }
}
```

**应对**：
- 渐进式迁移，每次只迁移一个 ViewModel
